# CropTransfer AT

Früherkennung von Stress und Ertragsverlust auf einzelnen Maisfeldern aus Satelliten-Zeitreihen, Wetter und Boden – gelernt an US-Feldern mit gemessenem Ertrag (viele Jahre), dann eingefroren und ohne Anpassung in Österreich (Steiermark) als Beweis getestet; ergänzt um einen regionalen Transfer-Test EU → Österreich (CY-Bench).

Projekt für den Bundeswettbewerb Künstliche Intelligenz (BWKI) Österreich.
