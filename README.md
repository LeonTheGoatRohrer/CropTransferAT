# CropTransfer AT

Früherkennung von Stress und Ertragsverlust auf einzelnen Maisfeldern in der Steiermark aus Sentinel-2-Zeitreihen, Wetter-, Boden- und Bodenfeuchtedaten – ohne Feld-Ertragsdaten, validiert gegen offizielle Regionalerträge, ergänzt um einen internationalen Transfer-Test (CY-Bench).

Projekt für den Bundeswettbewerb Künstliche Intelligenz (BWKI) Österreich.
